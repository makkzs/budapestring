# Budapest kör · Budapest Ring

Gyalogos körtúra Budapest körül — 102,7 km, ~1050 m szint, körbeér.
A honlap: **https://budapestring.hu**

A `track/budapest-kor.gpx` a teljes kör. Az `index.html` az egész oldal:
egyetlen fájl, Leaflet CDN-ről, semmi más.

Hiba a nyomvonalban, rossz megállónév, elírás: `ring@budapestring.hu`,
vagy nyiss egy issue-t itt.

A walking route **around** Budapest — 102.7 km, ~1050 m of ascent, a closed
circle. Site: **https://budapestring.hu**

`track/budapest-kor.gpx` is the whole ring. `index.html` is the whole site.

Corrections by mail to `ring@budapestring.hu`, or open an issue.
